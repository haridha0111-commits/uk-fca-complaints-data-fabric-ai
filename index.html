Analyst assistance · read-only

Grounded AI enablement

Let an analyst ask questions about official aggregates. The numerical response must come from a reviewed SQL query and cite its period and source.

Illustrative question

“How did overdraft complaint volumes change from 2025 H1 to H2?”

Source-backed response pattern
FCA reports 16,188 opened overdraft complaints in 2025 H1 and 26,456 in 2025 H2: an increase of 10,268 (63.4%). This is an observed change in aggregate counts; the dataset does not establish why it happened.

Source: FCA, Aggregate complaints data: 2025 H2

This is an example response built from published source values. No language model is connected in this prototype.

Controls before a real assistant

Data accessAllowlisted aggregate views only
Query modeRead-only, parameterized SQL
Answer groundingSource, period and query result
Unsupported “why”Explain evidence limit and abstain
Human roleReview before reuse or action
EvaluationAccuracy, citations, safe abstention
No individual-level predictions, complaint narratives, consumer eligibility decisions or real-time alerting are supported by these data. A production AI use needs the actual firm’s privacy, security, conduct and model-risk review.
